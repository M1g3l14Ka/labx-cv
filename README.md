# Portfolio & AI Assistant

Интерактивное SPA-приложение портфолио с полноценной серверной логикой, автоматизированной системой уведомлений и интегрированным ИИ-ассистентом на базе Gemini API.

**Дэмо:** https://labx.mkfox.tech/

---

## Технологический стек и архитектурные решения

* **Framework:** **Next.js 16 (App Router)** + **React 19**.
* **Language:** **TypeScript**
* **Styling & UI:** **Tailwind CSS v4**
* **Backend:** **Node.js**, `@google/generative-ai`, `nodemailer`
---

## Ключевой функционал и реализация

### 1. Асинхронный пайплайн обработки форм
* **Клиентская часть:** Валидация полей ввода, управление состоянием отправки.
* **Серверная часть (Server Action):** Данные передаются в изолированный серверный модуль. С помощью `Promise.all` реализована параллельная генерация и отправка двух независимых HTML-писем:
  1. Лид-уведомление для владельца сайта со всеми контактными данными.
  2. Транзакционное письмо-автоответчик для пользователя с подтверждением получения заявки.
* **Инфраструктура:** В качестве SMTP-транспорта настроен локальный сервер с авторизацией через App Passwords.

### 2. Интеграция AI-Контекста (Gemini API)
В интерфейс внедрен интерактивный компонент «AI-Ассистент»:
* На бэкенде развернут стриминг ответов через `@google/generative-ai` с использованием модели **Gemini 3.5 Flash**.
* Модели передан кастомный системный промпт - информация об опыте, стеке и проектах, что превращает её в изолированного агента информации, способного отвечать на вопросы рекрутеров в режиме реального времени.
